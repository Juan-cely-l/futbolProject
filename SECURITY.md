# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**.

Instead, send a description of the issue to the repository owner directly via GitHub. You can expect an acknowledgment within 48 hours and a resolution plan within 7 days.
